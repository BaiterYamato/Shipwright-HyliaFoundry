# Patch v10 Core — Ecosystem & Tooling

## Goal
Deliver a production-grade modding workflow around validation, deterministic packaging, trust/permissions scaffolding, and documentation-first onboarding.

## Core checkpoints
1. Add `modtool` command surface (`init`, `validate`, `pack`, `sign`, `doctor`, `diff`, `report`).
2. Add packaging/security/tool-report contract docs (v2/v1 schemas).
3. Add framework wiki + generated contract/registry index artifacts.
4. Add starter templates (framework/content/pack) with thin-modloader guidance.
5. Keep non-stable channels gated in modloader UI until v1.0.
