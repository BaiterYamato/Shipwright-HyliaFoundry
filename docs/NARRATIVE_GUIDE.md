# NARRATIVE_GUIDE

Patch v9 narrative runtime adds dialogue, quests, flags, and timelines as data-driven catalogs.

## Required capabilities (pick what you need)
- `narrative.dialogue.v1`
- `narrative.quests.v1`
- `narrative.flags.v1`
- `narrative.timeline.v1`

## Core actions
- `narrative.startDialogue`
- `narrative.chooseOption`
- `narrative.advanceDialogue`
- `narrative.setFlag`
- `narrative.clearFlag`
- `narrative.startQuest`
- `narrative.updateObjective`
- `narrative.startTimeline`
- `narrative.skipTimeline`
