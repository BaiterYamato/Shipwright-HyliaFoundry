# SSS (Sylian Spell Systems) Framework Demo

Library-style API v4 mod that ships reusable catalog content:

- FX presets (`fx.presets.v1`)
- Status catalog (`statuses.catalog.v1`)
- State catalog (`states.catalog.v1`)
- Spell catalog (`spells.catalog.v1`)

This package is intended as a dependency base for content packs.
