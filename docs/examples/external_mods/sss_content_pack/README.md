# SSS Content Pack Demo

Dependent content-pack example (`com.sylian.sss_content_pack`) for API v4.

- Dependency: `com.sylian.sss` in range `>=0.1.0 <0.2.0`
- Items:
  - `Firewall Staff` (hammer impact trigger)
  - `Levitation Glove` (cast on use)
- Effects are authored through statuses, spells, AoE, and FX presets.
