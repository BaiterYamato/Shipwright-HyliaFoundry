# Item State Machine Demo

Prova API v4 de `items.state_machine.v1`. Equipe o Martelo de Estados e use o botao de acao para exercitar
`select`, `press`, `hold`, `release`, `deselect` e `impact`. As transicoes emitem notificacoes, exceto o `hold`
continuo, que permanece silencioso para nao gerar spam.
