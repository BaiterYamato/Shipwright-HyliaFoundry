# NativeSmoke (Native SDK Mod)

Generated by `modtool init-native`.

## Purpose
- Native DLL-backed external mod for Windows-first API v4 workflows.

## Build
1. Run `tools/external_mods/modtool.ps1 build-sdk-sample -Path <this_mod>`
2. Confirm `native/win64/plugin.dll` exists
3. Run:
   - `tools/external_mods/modtool.ps1 validate -Path <this_mod>`
   - `tools/external_mods/modtool.ps1 doctor-native -Path <mods_root>`
   - `tools/external_mods/modtool.ps1 pack -Path <this_mod> -IncludePdb`

## Notes
- The sample plugin uses the stable native SDK surface only.
- Switch `runtime.nativeMode` to `raw` only when you also declare and grant `nativeinterop.raw`.
